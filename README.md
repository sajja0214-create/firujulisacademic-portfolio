## Deploy on Vercel
1. Extract this ZIP file.
2. Create a new GitHub repository and upload all files from this folder, including `profile.jpg`.
3. Sign in to Vercel and select **Add New → Project**.
4. Import the GitHub repository.
5. For a plain static site, leave the framework preset as **Other** and leave the build command and output directory blank (or use the defaults Vercel detects).
6. Select **Deploy**. Vercel will provide the public website URL after deployment.

This package has not been deployed to a live Vercel account.
